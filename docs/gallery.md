## Regenerating the images

To regenerate the images, run the scripts from any directory. Each figure is written to
`examples/`, next to the scripts, as PNG (600 dpi), SVG, and PDF:

```bash
python examples/styles_demo.py
python examples/personal_demo.py
python examples/palettes_demo.py
```

## Conventions

The images use the Personal style, except the `graphpadprism_*` images in the GraphPadPrism style
and the Matplotlib-defaults image of the [style comparison](#style-comparison). Each figure is laid
out in round inches (its size, the position and size of each axes, and the anchors of legends and
titles), and the files are saved uncropped with `save_figure`, so they keep that size. The README
and these pages show every image at 100 pixels per inch of figure width, so the text of each
figure appears at the same scale. Variables in labels and legends are math text, such as `$x$` and
`$\sin(x)$`. The scripts need Arial Regular and Italic installed, and `styles_demo.py` Arial Bold
and Bold Italic as well; they exit with an error without them, instead of writing images in a
fallback font.
